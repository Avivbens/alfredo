## Description

Search GIPHY for GIFs and copy them straight from [Alfred](https://www.alfredapp.com/).

## Prerequisites

The workflow searches with your own GIPHY API key:

1. Create an app in the [GIPHY developer dashboard](https://developers.giphy.com/dashboard) and copy its API key.
1. Paste the key in the workflow configuration.

A new key starts as a beta key, which allows 100 GIPHY calls an hour.
Each pause while you type runs a search and spends a call, while reopening your last search within an hour is free.

## Features 🥷

- A thumbnail next to every GIF 🖼️
- <kbd>⇧</kbd> plays the GIF large in Quick Look
- Alfred stays open after a copy, so you can copy several GIFs from one search
- Pick how many results to show and the highest content rating

## Usage

Type `gif` and what you're looking for, e.g. `gif hope`.
The keyword is configurable in the workflow settings if `gif` clashes with something else you use.

<kbd>↩</kbd> copies the GIF URL, and Alfred keeps the results open for the next pick.
