## Description

Search contacts and engage with them via [Alfred](https://www.alfredapp.com/).

## Features 🥷

### Fuzzy Search

Search for a contact by typing a part of their name, phone number or email.

### Supported Phone Number Formats

The workflow accepts a default country code, used when a contact's phone number has none.

All phone number formats are supported, including:

- `+1-50-1234567`
- `+1501234567`
- `050-1234567`
- `0501234567`
- `(808) 1234 567`
- `+1 (808) 1234 567`
- `(808)1234567`

## Usage

Search contacts via the keyword `ec<RELATED_APP>`.
A list of all matched contacts will be displayed, and you can select a contact by pressing `Enter`.
The workflow then opens the related app with the selected contact.

### Supported Apps

- WhatsApp: `ecw`
- SMS: `ecs`
- Call: `ecc`
- Mail: `ecm`
- FaceTime Audio: `ecfa`
- FaceTime Video: `ecf`
