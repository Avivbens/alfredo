## Description

Encrypt files and folders into a password-protected AES-256 zip, straight from Alfred's action menu 🔒

## Features 🥷

- Pack any selection of files and folders into one encrypted zip
- AES-256 encryption, opened by Mac, iPhone, Windows and Linux unzip apps
- A strong generated password, copied without leaving it in clipboard history 🔑

## Usage

Select files or folders in Finder, open Alfred's action menu and choose `Encrypt with Password`.
Type the password twice, and the zip appears next to the first selected item.
Or press `Generate` for a strong password - it is copied to the clipboard without landing in clipboard history.

The names of the files inside the zip stay readable without the password - only their contents are encrypted.
Turn on `Hide file names` in the workflow settings to hide them too - recipients then unzip twice.
To open it, use any unzip app with AES support, such as Keka, The Unarchiver or 7-Zip.
